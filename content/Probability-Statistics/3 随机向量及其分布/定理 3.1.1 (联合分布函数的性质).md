> [!theorem] 定理 3.1.1 (联合分布函数的性质)
> 设 $\left( {\Omega,\mathcal{F}, P}\right)$ 为概率空间, 随机向量 $\left( {{X}_{1},{X}_{2},\cdots,{X}_{n}}\right)$ 的联合分布函数为 ${F}_{{X}_{1},{X}_{2},\cdots,{X}_{n}}$, 则
> 1. $0 \leq  {F}_{{X}_{1},{X}_{2},\cdots,{X}_{n}}\left( {{x}_{1},{x}_{2},\cdots,{x}_{n}}\right)  \leq  1,\;\forall \left( {{x}_{1},{x}_{2},\cdots,{x}_{n}}\right)  \in  {\mathbb{R}}^{n}$.
> 2. ${F}_{{X}_{1},{X}_{2},\cdots,{X}_{n}}\left( {{x}_{1},{x}_{2},\cdots,{x}_{n}}\right)$ 关于每个变元 ${x}_{i}$ 单增右连续, $i = 1,2,\cdots, n$.
> 3. 极限满足
> 	1. $\mathop{\lim }\limits_{{{x}_{i} \rightarrow   - \infty }}{F}_{{X}_{1},{X}_{2},\cdots,{X}_{n}}\left( {{x}_{1},{x}_{2},\cdots,{x}_{n}}\right)  = 0$, $i = 1,2,\cdots, n$. 
> 	2. $\mathop{\lim }\limits_{\substack{{{x}_{i} \rightarrow  \infty } \\  {i = 1,2,\cdots, n} }}{F}_{{X}_{1},{X}_{2},\cdots,{X}_{n}}\left( {{x}_{1},{x}_{2},\cdots,{x}_{n}}\right)  = 1.$
> 3. 对任意 $\left( {{x}_{1},{x}_{2},\cdots,{x}_{n}}\right)  \in  {\mathbb{R}}^{n}$ 和 ${h}_{i} > 0, i = 1,2,\cdots, n$ 有 $${\bigtriangleup }_{\left( {x}_{1},{x}_{2},\cdots,{x}_{n}\right) }^{\left( {x}_{1} + {h}_{1},{x}_{2} + {h}_{2},\cdots,{x}_{n} + {h}_{n}\right) }{F}_{{X}_{1},{X}_{2},\cdots,{X}_{n}}\left( {{t}_{1},{t}_{2},\cdots,{t}_{n}}\right)  \geq  0. \tag{3.1.2}$$
^statement

## 证明
定理 3.1.1 的 (i)-(iii) 直观上容易理解,
对于 (iv),我们就 $n = 2$ 的情况给出证明. 事实上
$$
\begin{align}
0 &\leq P\left( x_1 < X_1 \leq x_1 + h_1, x_2 < X_2 \leq x_2 + h_2 \right) \\
    &= P\left( X_1 \leq x_1 + h_1, X_2 \leq x_2 + h_2 \right) - P\left( X_1 \leq x_1, X_2 \leq x_2 + h_2 \right) \\
    &\quad - P\left( X_1 \leq x_1 + h_1, X_2 \leq x_2 \right) + P\left( X_1 \leq x_1, X_2 \leq x_2 \right) \\
    &= F_{X_1, X_2}\left( x_1 + h_1, x_2 + h_2 \right) - F_{X_1, X_2}\left( x_1, x_2 + h_2 \right) \\
    &\quad - F_{X_1, X_2}\left( x_1 + h_1, x_2 \right) + F_{X_1, X_2}\left( x_1, x_2 \right) \\
    &= \Delta_{x_1}^{x_1 + h_1} \left( F_{X_1, X_2}\left( t_1, x_2 + h_2 \right) - F_{X_1, X_2}\left( t_1, x_2 \right) \right) \\
    &= \Delta_{(x_1, x_2)}^{(x_1 + h_1, x_2 + h_2)} F_{X_1, X_2}\left( t_1, t_2 \right).
\end{align}
$$

从以上证明,类似地可以证明 (3.1.2) 左端的 $n$ 阶差分
$$
\begin{align}
&\Delta_{(x_1, x_2, \cdots, x_n)}^{(x_1 + h_1, x_2 + h_2, \cdots, x_n + h_n)} F_{X_1, X_2, \cdots, X_n}(t_1, t_2, \cdots, t_n) \\
= & P\left( \omega \in \Omega : \bigcap_{i = 1}^{n} \left\{ x_i < X_i(\omega) \leq x_i + h_i \right\} \right), \tag{3.1.3}
\end{align}
$$
