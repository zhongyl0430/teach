> [!question] 5
> 设随机变量 $X$ 与 $Y$ 相互独立，且 $X \sim B(1, p), Y \sim B(2, p), 0 < p < 1$, 则 $X+Y$ 与 $X-Y$ 的相关系数为 (  )。
> 	(A) $- \frac{1}{6}$  (B) $\frac{3}{4}$  (C) $- \frac{1}{5}$  (D) $- \frac{1}{3}$
^question

## 解答步骤与解释：
1.  相关系数 $\rho(U, V) = \frac{Cov(U, V)}{\sqrt{Var(U)Var(V)}}$，其中 $U = X+Y, V = X-Y$。
2.  计算期望和方差：
    * $X \sim B(1, p) \implies E(X) = p, Var(X) = p(1-p)$。
    * $Y \sim B(2, p) \implies E(Y) = 2p, Var(Y) = 2p(1-p)$。
3.  计算 $Var(U)$ 和 $Var(V)$：
    * $Var(U) = Var(X+Y)$。由于 $X, Y$ 独立, $Var(X+Y) = Var(X) + Var(Y) = p(1-p) + 2p(1-p) = 3p(1-p)$。
    * $Var(V) = Var(X-Y)$。由于 $X, Y$ 独立, $Var(X-Y) = Var(X) + Var(-Y) = Var(X) + (-1)^2 Var(Y) = Var(X) + Var(Y) = 3p(1-p)$。
4.  计算 $Cov(U, V)$：
    $Cov(U, V) = Cov(X+Y, X-Y)$
    $= Cov(X, X) - Cov(X, Y) + Cov(Y, X) - Cov(Y, Y)$
    $= Var(X) - Cov(X, Y) + Cov(X, Y) - Var(Y)$
    由于 $X, Y$ 独立, $Cov(X, Y) = 0$。
    $Cov(U, V) = Var(X) - Var(Y) = p(1-p) - 2p(1-p) = -p(1-p)$。
5.  计算相关系数：
    $\rho(U, V) = \frac{-p(1-p)}{\sqrt{3p(1-p) \cdot 3p(1-p)}} = \frac{-p(1-p)}{3p(1-p)}$。
    因为 $0 < p < 1$, $p(1-p) \neq 0$。
    $\rho(U, V) = -\frac{1}{3}$。

答案：(D)
