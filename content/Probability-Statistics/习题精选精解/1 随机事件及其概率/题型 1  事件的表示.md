# 方法与技巧 
任意一个随机事件均可以表示为一个或几个与其等价的形式. 
在概率的计算中,可以根据条件的不同而选用不同的等价形式,大家在做关于随机事件的关系及运算的题目时, 应该注意下面几个结论的应用:
1. $A = {AB} + A\bar{B}$, ${AB}$ 与 $A\bar{B}$ 互不相容；
2. 当 $A, B$ 互不相容时, $A - B = A$; ${AB} = \varnothing$; $\left( {A + B}\right)  - B = A$;
3. 当 $B \subset  A$ 时, $A + B = A$; ${AB} = B$; $\left( {A - B}\right)  + B = A$;
4. $A - B = A - {AB} = A\bar{B}$.

# 1.1
设 $A, B, C$ 为三事件,用 $A, B, C$ 的运算关系表示下列各事件.
1. $A$ 发生, $B$ 与 $C$ 不发生；
2. $A$ 与 $B$ 都发生,而 $C$ 不发生;
3. $A, B, C$ 中至少有一个发生; 
4. $A, B, C$ 都发生;
5. $A, B, C$ 都不发生; 
6. $A, B, C$ 中不多于一个发生;
7. $A, B, C$ 中不多于两个发生; 
8. $A, B, C$ 中至少有两个发生.

## 解
1. $A\bar{B}\bar{C}$ 
2. ${AB}\bar{C}$ 
3. $A \cup  B \cup  C$
4. ${ABC}$
5. $\bar{A}\bar{B}\bar{C}$
6. $\bar{A}\bar{B}\bar{C} \cup  A\bar{B}\bar{C} \cup  \bar{A}B\bar{C} \cup  \bar{A}\bar{B}C$ 或 $\bar{A}\bar{B} \cup  \bar{A}\bar{C} \cup  \bar{B}\bar{C}$
7. $\overline{ABC}$ 或 $\bar{A} \cup  \bar{B} \cup  \bar{C}$ 
8. ${AB} \cup  {BC} \cup  {AC}$.

# 1.2
在电炉上安装了 4 个温控器,其显示温度的误差是随机的. 
在使用过程中, 只要有两个温控器显示的温度不低于临界温度 ${t}_{0}$,电炉就断电. 
以 $E$ 表示事件“电炉断电”, 而 ${T}_{\left( 1\right) } \leq  {T}_{\left( 2\right) }$ $\leq  {T}_{\left( 3\right) } \leq  {T}_{\left( 4\right) }$ 为 4 个温控器显示的按递增顺序排列的温度值,
则事件 $E$ 等于(   ).

(A) $\left\{  {{T}_{\left( 1\right) } \geq  {t}_{0}}\right\}$ (B) $\left\{  {{T}_{\left( 2\right) } \geq  {t}_{0}}\right\}$ (C) $\left\{  {{T}_{\left( 3\right) } \geq  {t}_{0}}\right\}$ (D) $\left\{  {{T}_{\left( 4\right) } \geq  {t}_{0}}\right\}$

## 解
$\left. \left\{  {{T}_{\left( 1\right) } \geq  {t}_{0}}\right) \right\}$ 表示四个温控器显示温度均不低于 ${t}_{0}$

$\left\{  {{T}_{\left( 2\right) } \geq  {t}_{0}}\right\}$ 表示至少三个温控器显示温度均不低于 ${t}_{0}$

$\left\{  {{T}_{\left( 3\right) } \geq  {t}_{0}}\right\}$ 表示至少二个温控器显示温度均不低于 ${t}_{0}$

$\left\{  {{T}_{\left( 4\right) } \geq  {t}_{0}}\right\}$ 表示至少一个温控器显示温度均不低于 ${t}_{0}$

故应选(C).
