# 方法与技巧
若总体非正态或者总体分布未知时,可采用大样本 (样本容量一般大于 50), 利用中心极限定理, 按照正态近似对参数进行假设检验.

# 3.26
某车间承担了生产额定抗拉强度为 105 的合金线的任务,从该车间生产出的合金线产品中随机地抽出 100 根,测得抗拉强度均值 $\bar{x} = {104.5}$,标准差 $s = {1.8}$,问这批产品是否符合标准? $\left( {\alpha  = {0.05}}\right)$

## 解
${H}_{0} : \mu  \geq  {105},{H}_{1} : \mu  < {105}$.

选统计量 $T = \frac{\bar{X} - {\mu }_{0}}{\frac{S}{\sqrt{n}}}$,因为 $n = {100}$ 属于大样本,所以近似地 $T \sim  N\left( {0,1}\right)$.

对 $\alpha  = {0.05}$,拒绝域为 $T <  - {u}_{\alpha }$,查得 ${u}_{\alpha } = {u}_{0.05} = {1.645}$,

求出 $t = \frac{{104.5} - {105}}{\frac{1.8}{10}} =  - {2.778} <  - {1.645}$,

故拒绝 ${H}_{0}$,接受 ${H}_{1}$,即认为这批产品不符合标准.

# 3.27
设有一大批产品,从中任取 100 件,经检验有正品 92 件,问能不能说这批产品的正品率高于 90%? $\left( {\alpha  = {0.05}}\right)$

## 解
这是 $\left( {0 - 1}\right)$ 分布总体的参数 $p$ 的假设检验问题.

因为 ${X}_{i} \sim  \left( {0 - 1}\right)$ 分布, $i = 1,2,\cdots,{100}$,由中心极限定理
$$
\bar{X} = \frac{1}{n}\mathop{\sum }\limits_{{i = 1}}^{n}{X}_{i}\overset{\text{ 近似 }}{ \sim  }N\left( {p,\frac{p\left( {1 - p}\right) }{n}}\right).
$$

提出假设 ${H}_{0} : p \leq  {p}_{0} = {0.9},{H}_{1} : p > {p}_{0}$.

选统计量
$$
U = \frac{\bar{X} - {p}_{0}}{\sqrt{\frac{{p}_{0}\left( {1 - {p}_{0}}\right) }{n}}}\overset{\text{近似}}{ \sim  }N\left( {0,1}\right)
$$

拒绝域为 $U > {u}_{\alpha }$.

查得 ${u}_{\alpha } = {u}_{0.05} = {1.645}$,算出 $u = \frac{\bar{x} - {0.9}}{\sqrt{\frac{{0.9} \times  {0.1}}{100}}} = \frac{\frac{92}{100} - {0.9}}{\sqrt{\frac{{0.9} \times  {0.1}}{100}}} \approx  {0.6667}$.

因为 ${0.6667} < {1.645}$,即 $u < {u}_{a}$,

故接受 ${H}_{0}$,拒绝 ${H}_{1}$,不能说正品率高于 ${90}\%$.
