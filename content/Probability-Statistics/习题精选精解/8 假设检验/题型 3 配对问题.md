设 ${D}_{i} = {X}_{i} - {Y}_{i}\left( {i = 1,2,\cdots,{10}}\right)$ 是来自正态总体 $N\left( {{\mu }_{D},{\sigma }_{D}^{2}}\right)$ 的样本, ${\mu }_{D},{\sigma }_{D}^{2}$ 均未知,问以这两种种子种植的谷物的产量是否有显著的差异 (取 $\alpha  = {0.05}$ )?

## 解
设 $D = X - Y \sim  N\left( {{\mu }_{D},{\sigma }_{D}^{2}}\right),\;{D}_{i} = {X}_{i} - {Y}_{i}$.

检验假设 ${H}_{0} : {\mu }_{D} = 0,{H}_{1} : {\mu }_{D} \neq  0$.

该检验的拒绝域为 $\left| t\right|  = \left| \frac{\bar{D} - 0}{\frac{S}{\sqrt{n}}}\right|  \geq  {t}_{\frac{\alpha }{2}}\left( {n - 1}\right)$,此处 $\alpha  = {0.05},\frac{\alpha }{2} = {0.025}, n = {10}$,

查表知 ${t}_{\frac{\alpha }{2}}\left( {n - 1}\right)  = {2.2622}$,计算得 $\bar{d} =  - {0.2},{s}^{2} = {19.822}, s = {4.45}$,

于是 $\left| t\right|  = \left| \frac{-{0.2} - 0}{\frac{4.45}{\sqrt{10}}}\right|  = {0.1424} < {2.2622}$.

$t$ 没落在拒绝域,故接受 ${H}_{0}$,认为没有显著差异.

设 ${D}_{i} = {X}_{i} - {Y}_{i}\left( {i = 1,2,\cdots,{15}}\right)$ 是来自正态总体 $N\left( {{\mu }_{D},{\sigma }_{D}^{2}}\right)$ 的样本, ${\mu }_{D},{\sigma }_{D}^{2}$ 均未知,问是否可以认为用材料 $A$ 制作的后跟比用材料 $B$ 制作的耐穿 $\left( {\alpha  = {0.05}}\right)$ ?

## 解
成对试验 $D = X - Y \sim  N\left( {{\mu }_{D},{\sigma }_{D}^{2}}\right),{D}_{i} = {X}_{i} - {Y}_{i}$.

检验假设 ${H}_{0} : {\mu }_{D} \leq  0,{H}_{1} : {\mu }_{D} > 0$.

因 ${\sigma }_{D}^{2}$ 未知,拒绝域为 $t = \frac{\bar{D} - 0}{\frac{{S}_{D}}{\sqrt{n}}} \geq  {t}_{\alpha }\left( {n - 1}\right)$,这里 $n = {15},\alpha  = {0.05},{t}_{0.05}\left( {14}\right)  = {1.7613}$, 概率论与数理统计习题精选精解

计算得 $\bar{D} = {0.553},{S}_{D}^{2} = {\left( {1.0225}\right) }^{2}$,于是 $t = \frac{{0.553} - 0}{\frac{1.0225}{\sqrt{15}}} = {2.0958} > {1.7613}$,

$t$ 落在拒绝域中,拒绝 ${H}_{0}$,认为 $A$ 比 $B$ 耐穿.
