已知某厂生产的滚珠直径 $X \sim  N\left( {\mu,{0.06}}\right)$. 从某天生产的滚珠中随机地抽取 6 只, 测得直径为 (单位: mm)

$\begin{array}{llllll} {14.6} & {15.1} & {14.9} & {14.8} & {15.2} & {15.1} \end{array}$

试求 $\mu$ 的置信度为 0.95 的区间估计.

解 由于
$$
\bar{x} = \frac{1}{6}\left( {{14.6} + {15.1} + {14.9} + {14.8} + {15.2} + {15.1}}\right)  = {14.95},
$$

$\sigma  = \sqrt{0.06},\alpha  = {0.05}$,查表或用 $\mathrm{R}$ 软件计算得 ${u}_{0.975} = {1.96}$,用 (7.3.5) 得到 $\mu$ 的置信度为 0.95 的区间估计 [14.754, 15.146].

另外,请读者执行如下 python 程序,看有什么结果.

```python
import numpy as np
from scipy.stats import norm

# 定义数据向量 x
x = np.array([14.6, 15.1, 14.9, 14.8, 15.2, 15.1])

# 定义标准差 sigma
sigma = np.sqrt(0.06)

# 定义显著性水平 alpha
alpha = 0.05

# 计算样本均值的负值 z1
z1 = -np.mean(x)

# 计算置信区间的边界值 z2
z2 = norm.ppf(1 - alpha / 2) * sigma / np.sqrt(len(x))

# 计算置信区间并以列表形式返回
confidence_interval = [z1 - z2, z1 + z2]

# 输出置信区间
print({"c.i": confidence_interval})
```
