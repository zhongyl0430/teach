负向量是唯一的. 

以后把 $\alpha$ 的负向量记作 $- \alpha$.

证明 
设 $\mathbf{\beta },\mathbf{\gamma }$ 都是 $\mathbf{\alpha }$ 的负向量. 我们有
$$
\beta = \beta + 0 = \beta + \left( {\alpha + \gamma }\right) = \left( {\beta + \alpha }\right) + \gamma = \left( {\alpha + \beta }\right) + \gamma = 0 + \gamma = \gamma + 0 = \gamma.
$$
