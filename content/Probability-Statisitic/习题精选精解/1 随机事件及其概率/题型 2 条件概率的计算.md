# 方法与技巧 
计算条件概率 $P\left( {B \mid  A}\right)$ 的方法有两种: ① 按条件概率的含义,直接求出 $P\left( {B \mid  A}\right)$. 注意到,在求 $P\left( {B \mid  A}\right)$ 时已知 $A$ 已发生,样本空间 $S$ 中所有不属于 $A$ 的样本点都被排除,原有的样本空间 $S$ 缩减成为 ${S}^{\prime }$. 在 ${S}^{\prime }$ 中计算事件 $B$ 的概率就得到 $P\left( {B \mid  A}\right)$. ② 在 $S$ 中计算 $P\left( {AB}\right)$ 及 $P\left( A\right)$,再按 $\frac{P\left( {AB}\right) }{P\left( A\right) }$ 式求得 $P\left( {B \mid  A}\right)$.

# 3.6
设 $A, B, C$ 是随机事件, $A$ 与 $C$ 互不相容, $P\left( {AB}\right)  = \frac{1}{2}, P\left( C\right)  = \frac{1}{3}$,则 $P\left( {{AB} \mid  \bar{C}}\right)  =$ _____.

## 解 
由条件概率的定义, $P\left( {{AB} \mid  \bar{C}}\right)  = \frac{P\left( {{AB}\bar{C}}\right) }{P\left( \bar{C}\right) }$,因为 $A, C$ 互不相容,

所以 $A\bar{C} = A$,因此 $P\left( {{AB}\bar{C}}\right)  = P\left( {AB}\right)$,从而原式 $= \frac{P\left( {AB}\right) }{1 - P\left( C\right) } = \frac{\frac{1}{2}}{1 - \frac{1}{3}} = \frac{3}{4}$.

另外,除了用互斥定义得到 $P\left( {{AB}\bar{C}}\right)  = P\left( {AB}\right)$,还可以用性质一一减法公式:

$$
P\left( {{AB}\bar{C}}\right)  = P\left( {AB}\right)  - P\left( {ABC}\right),
$$

由

$$
P\left( {AC}\right)  = 0 \Rightarrow  P\left( {ABC}\right)  = 0,
$$

从而

$$
P\left( {{AB}\bar{C}}\right)  = P\left( {AB}\right) \text{.}
$$

# 3.7
设某种动物由出生算起活 20 年以上的概率为 0.8,活 25 年以上的概率为 0.4. 如果现在有一只 20 岁的这种动物, 问它能活到 25 岁以上的概率是多少?

## 解 
设事件 $B =$ “能活 20 年以上”, $A =$ “能活 25 年以上”.

按题意, $P\left( B\right)  = {0.8}$,由于 $A \subset  B$,所以 ${BA} = A$,因此 $P\left( {AB}\right)  = P\left( A\right)  = {0.4}$.

由条件概率的定义,得 $P\left( {A \mid  B}\right)  = \frac{P\left( {AB}\right) }{P\left( B\right) } = \frac{0.4}{0.8} = {0.5}$.

# 3.8
设 $A, B$ 为两个随机事件,且 $0 < P\left( A\right)  < 1,0 < P\left( B\right)  < 1$,如果 $P\left( {A \mid  B}\right)  = 1$,则_____.

(A) $P\left( {\bar{B} \mid  \bar{A}}\right)  = 1$. (B) $P\left( {A \mid  \bar{B}}\right)  = 0$. (C) $P\left( {A \cup  B}\right)  = 1$. (D) $P\left( {B \mid  A}\right)  = 1$.

## 解 
因为 $P\left( {A \mid  B}\right)  = \frac{P\left( {AB}\right) }{P\left( B\right) } = 1$,所以 $P\left( {AB}\right)  = P\left( B\right)$

则 $P\left( {\bar{B} \mid  \bar{A}}\right)  = \frac{P\left( {\bar{A} \mid  \bar{B}}\right) }{P\left( \bar{A}\right) } = \frac{1 - P\left( {A \cup  B}\right) }{1 - P\left( A\right) }$

$= \frac{1 - \left\lbrack  {P\left( A\right)  + P\left( B\right)  - P\left( {AB}\right) }\right\rbrack  }{1 - P\left( A\right) }$

$= \frac{1 - P\left( A\right) }{1 - P\left( A\right) } = 1.$

故应选(A).
