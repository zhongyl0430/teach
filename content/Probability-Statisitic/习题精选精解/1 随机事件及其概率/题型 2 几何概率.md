# 方法与技巧 
根据题意建立正确的几何概型往往是解题的关键, 另外, 几何概率的计算中往往需要利用定积分及重积分求面积或体积, 因此要求考生对微积分知识要熟悉.

# 2.7
在区间 $\left( {0,1}\right)$ 中随机地取两个数,则这两个数之差的绝对值小于 $\frac{1}{2}$ 的概率为_____.

![0195317d-ba2a-736d-8e6e-9afc1cf09b00_5_675_1050_312_279_0.jpg](images/0195317d-ba2a-736d-8e6e-9afc1cf09b00_5_675_1050_312_279_0.jpg)

图 1-2.7

## 解 
设 $x, y$ 为所取的两个数,则 $0 < x < 1,0 < y < 1, x, y$ 所有可能取值结果对应的集合记为 $S$,事件“两个数之差的绝对值小于 $\frac{1}{2}$ ” 记为 $A$. 则样本空间 $S = \{ \left( {x, y}\right)  \mid  0 < x < 1,0 < y < 1\}$, 事件 $A = \left\{  {\left( {x, y}\right) \left| {\left( {x, y}\right)  \in  S,}\right| x - y \mid   < \frac{1}{2}}\right\}$ (如图 1-2.7 中阴影部分),故

$$
P\left( A\right)  = \frac{\Omega \left( A\right) }{\Omega \left( S\right) } = \frac{3/4}{1} = \frac{3}{4}.
$$

其中, $\Omega \left( A\right)$ 与 $\Omega \left( S\right)$ 分别表示 $A$ 与 $S$ 的面积.

# 2.8
有一根长 $l$ 的木棒,任意折成三段,恰好能构成一个三角形的概率为_____.

![0195317d-ba2a-736d-8e6e-9afc1cf09b00_6_988_187_293_297_0.jpg](images/0195317d-ba2a-736d-8e6e-9afc1cf09b00_6_988_187_293_297_0.jpg)

图 1-2.8

## 解 
设折得的三段长度为 $x, y$ 和 $l - x - y$,那么,样本空间 $\Omega  = \{ \left( {x, y}\right)  \mid  0 \leq  x \leq  l,0 \leq  y \leq  l,0 \leq  x + y \leq  l\}$,而随机事件 $A$ : “三段构成三角形” 相应的子区域 $G$ 应满足 “两边之和大于第三边” 的原则, 从而

$$
\left\{  \begin{array}{l} l - x - y < x + y \\  x < \left( {l - x - y}\right)  + y \\  y < \left( {l - x - y}\right)  + x \end{array}\right.
$$

即 $G = \left\{  {\left( {x, y}\right)  \mid  0 < x < \frac{l}{2},0 < y < \frac{l}{2},\frac{l}{2} < x + y < l}\right\}$.

从图 1-2.8 中可以得到相应的几何概率: $P\left( A\right)  = \frac{1}{4}$.
